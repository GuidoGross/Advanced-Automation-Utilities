# **Security**

## **Reporting a vulnerability**

Please do not report security vulnerabilities in a public issue, discussion, or pull request. Use GitHub's private vulnerability reporting feature for this repository if it is available. Otherwise, email the project maintainer at [grossguidoivan@gmail.com](mailto:grossguidoivan@gmail.com).

Include the affected library version, the relevant environment details, steps to reproduce the issue, its potential impact, and any suggested mitigation. A minimal proof of concept can help with assessment; do not include real credentials or other users' data.

You can expect an acknowledgment and follow-up after the report has been reviewed. Response and resolution times depend on the issue and maintainer availability; no fixed response-time guarantee is offered.

## **Public disclosure**

Please allow the maintainer an opportunity to investigate and coordinate a fix before sharing vulnerability details publicly. Do not publish exploit details or a proof of concept while the report is being assessed.
