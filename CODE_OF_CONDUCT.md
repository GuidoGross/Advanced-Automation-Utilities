# **Code of Conduct**

## **Our commitment**

We are committed to making participation in this project a respectful and welcoming experience for everyone, regardless of background, identity, experience, or perspective.

## **Expected behavior**

- Be respectful, considerate, and constructive in discussions and reviews.
- Give feedback about ideas and code, not personal characteristics.
- Accept differing viewpoints and respond to disagreement professionally.
- Help keep discussions focused, useful, and accessible to participants.

## **Unacceptable behavior**

- Harassment, intimidation, threats, or personal attacks.
- Insults, demeaning language, or unwanted sexual attention.
- Publishing another person's private information without permission.
- Deliberately disrupting project discussions or repeatedly ignoring moderation requests.

## **Scope**

This Code of Conduct applies in project spaces, including issues, pull requests, discussions, and other project-related communications. It also applies when someone is officially representing the project in public.

## **Enforcement**

Project maintainers are responsible for clarifying and enforcing this Code of Conduct. They may edit or remove content, close discussions, or restrict participation when necessary. Decisions will take the circumstances and impact into account.

To report a concern, contact the project maintainer at [grossguidoivan@gmail.com](mailto:grossguidoivan@gmail.com). Include relevant links and context when possible. Please avoid posting sensitive details in public project spaces.

## **Attribution**

This Code of Conduct is written for this project and draws on common open-source community standards.
